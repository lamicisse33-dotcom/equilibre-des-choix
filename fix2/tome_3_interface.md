# TOME 3 — Interface utilisateur : ÉQUILIBRE DES CHOIX

- **Design HUD** :
    - Minimalisme doré sur fond sombre.
    - Glassmorphism (flou d'arrière-plan) pour les panneaux d'information.
- **Feedback Visuel** :
    - **Danger** : Vignette rouge et barres pulsantes quand un pilier approche des seuils critiques (20/80).
    - **Harmonie** : Badge doré scintillant et aura visuelle.
    - **Previews** : Ombrage fantôme sur les barres de piliers lors du survol d'une carte pour anticiper son impact.
- **Navigation** :
    - Menu principal épuré avec accès rapide au Duel et aux Statistiques.
    - Historique du cycle accessible en jeu pour suivre les conséquences passées.
- **Accessibilité** :
    - Mode Clair/Sombre dynamique.
    - Contrôles simplifiés (un clic pour info, deux clics pour valider).
    - Adaptabilité mobile totale (Responsive Design).

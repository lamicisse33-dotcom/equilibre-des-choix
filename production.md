# TOME 15 — PRODUCTION : MÉTHODOLOGIE DU GARDIEN

Ce document définit l'ordre sacré des opérations pour le développement de **ÉQUILIBRE DES CHOIX**. Il sert de guide suprême pour assurer la cohérence entre la vision philosophique et l'exécution technique.

## Le Cycle de Création

### Étape 1 : Construire l'architecture
- Consolider le cœur du moteur (Game Engine).
- Structurer les contrôleurs (Card, UI, Audio, VFX, Home).
- Assurer la fluidité de la communication entre les modules ESM.

### Étape 2 : Construire les écrans
- Développer l'interface utilisateur (HUD, Menus, Overlays).
- Appliquer la direction UX (Mobile First, clarté absolue).
- Intégrer les retours visuels interactifs.

### Étape 3 : Construire les cartes
- Définir les données des cartes (Narrative Events).
- Intégrer les illustrations (IA / Art Direction).
- Coder les effets spéciaux et les types de rareté (Commun à Mythique).

### Étape 4 : Construire la balance
- Ajuster les poids des conséquences sur les 4 piliers.
- Équilibrer les probabilités d'apparition.
- Tester les courbes de difficulté et la progression.

### Étape 5 : Construire les animations
- Fluidifier les transitions entre les états de jeu.
- Ajouter du "Juice" (particules, secousses, flashs célestes).
- Animer la table de jeu 3D et les mouvements de cartes.

### Étape 6 : Intégrer les sons
- Implémenter l'ambiance sonore évolutive.
- Ajouter les bruitages d'impact et de succès.
- Synchroniser l'audio avec les événements visuels (Celestial Flash).

### Étape 7 : Tester
- Effectuer des tests de boucle de gameplay complète.
- Vérifier la robustesse de la persistence des données.
- Chasser les bugs de logique et les déséquilibres critiques.

### Étape 8 : Optimiser
- Améliorer les performances de rendu (Three.js / Canvas).
- Réduire les temps de chargement des assets.
- Raffiner le code pour une maintenance aisée.

### Étape 9 : Préparer la version finale
- Finaliser le branding (Identity, Icons, Manifest).
- Préparer les notes de mise à jour (Version 1.5.0+).
- Sceller le chapitre pour la prochaine expansion.
